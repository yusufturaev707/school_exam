# Button

Har ekranda bitta asosiy tugma; qolgan amallar ikkinchi darajali yoki matnli.

| variant | balandlik | qachon |
| --- | --- | --- |
| `bd-btn--primary` | `control-lg` 48px, `shadow-press` 3D qirra | Ekrandagi yagona asosiy amal |
| `bd-btn--light` | 48px, oq | Faqat `hero` (yashil) fon ustida asosiy amal |
| `bd-btn--secondary` | `control-md` 40px, `brand-soft` | Ikkinchi darajali amal |
| `bd-btn--ghost` | 40px, shaffof | Uchinchi darajali: “Keyinroq”, “Bekor qilish” |
| `bd-iconbtn` | 36px koʻrinish, 44px hit-area | Yopish, orqaga |

- Bosilganda `scale(.97)` (3D variantlarda qirra 3px pastga tushadi).
- Yozuv 15px/800, fe'l bilan boshlanadi: “Imtihonni boshlash”, “Oʻyinni boshlash”, “Yana oʻynash”.
- Oʻng tomonda faqat `arrowR` yoki `play` ikonkasi.
- Fokus: `focus` rangidagi 2px halqa, 2px offset.
