# Badge (Nishon)

Yutuq nishoni: 52px doira, ikonka 24px, ostida 11px nom.

- Ochilgan: yoʻnalish rangidagi `-soft` fon, ikkita halqa (`card` + `-soft`).
- Qulflangan (`is-locked`): `bg-tint` fon, `ink-3` ikonka, pastki oʻngda qulf belgisi — faqat rangsizlik emas.
- Bosh sahifada 4 ta bitta qatorda (`bd-badges`), Yutuqlar sahifasida 3 ustunli grid (`bd-badgegrid`).
- Yangi ochilganda maskot `xursand` + konfetti (natija ekranida).
