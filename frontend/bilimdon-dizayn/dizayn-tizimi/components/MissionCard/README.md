# MissionCard

Kunlik missiya — bitta qatorli bosiladigan karta (~64px): progress halqasi, vazifa, mukofot chipi.

- Matn: “Bugun 5 ta savol yech”, ostida bugungi intellektual topshiriq (“Naqsh ustasi”).
- Mukofot `+20` ⭐ chipda; bajarilganda halqa toʻladi va chip `success` rangiga oʻtadi.
- Butun karta bitta havola — bugungi topshiriqqa olib boradi. Bosh sahifa va Oʻyinlarni bogʻlaydi.
