# BottomNav

Pastki navigatsiya: 5 boʻlim — Bosh sahifa, Imtihon, Oʻyinlar, Natijalar, Profil.

- Balandlik `nav-h` (60px) + `env(safe-area-inset-bottom)`; sahifa kontentiga pastdan kamida 96px boʻshliq qoldiring.
- Ikonka 22px, yozuv 11px/700; faol boʻlim — `brand-soft` “pill” (52×28) + `brand-ink` 800 yozuv + `aria-current="page"`.
- Har bir element ≥ 52px balandlikda (hit-area).
- Oʻyinlar = `game` (gamepad) ikonkasi.
- Kompyuterda (≥1024px) chap yon panelga aylanadi.
