# Icon

Duotone ikonkalar: 2px chiziq + 22% shaffof toʻldirish, 24×24 setkada, yumaloq uchlar (Phosphor Duotone uslubi).

- `Bilimdon.icon(name, size)` SVG qatorini qaytaradi; HTML'da `<i data-ico="star" data-size="16"></i>`.
- Rang `currentColor` — ota elementning `color` qiymatidan oladi.
- Oʻlchamlar: kontentda `icon-md` (20px), navigatsiyada `icon-lg` (22px), chip ichida 16px.
- Reactda: `@phosphor-icons/react` ning `weight="duotone"` varianti bilan 1:1 almashtirsa boʻladi (`House`, `ClipboardText`, `GameController`, `ChartBar`, `User`, `Fire`, `Star`, `Sigma`, `PuzzlePiece`, `BookOpen`, `Brain`, `Eye`, `Compass`, `TextT`...).
- **Oʻyinlar boʻlimi uchun faqat `game` (gamepad)** — kolba ishlatilmaydi.
