# ExamHero

Bosh sahifaning asosiy bloki: imtihon holati + yagona asosiy amal. Balandligi ≤ 35% ekran (~220px).

- Tarkib: holat chipi → sarlavha (22px) → meta chiplar → `bd-btn--light` tugma. Maskot oʻng pastda, 88–96px.
- Fon `hero`, ustida tartibli naqsh (Σ, jumboq, “Aa”, “?”) 96px setkada, 9% shaffoflikda — tasodifiy shakllar yoʻq.
- **Yangi foydalanuvchi:** “Topshirish mumkin”, “Imtihonni boshlash”, maskot `ishora`.
- **Faol foydalanuvchi (topshirgan):** “Topshirildi”, natija halqasi 38/45, “Xatolar ustida ishlash”, maskot `xursand`.
- Sarlavha `max-width: 220px` — maskot bilan toʻqnashmaydi.
