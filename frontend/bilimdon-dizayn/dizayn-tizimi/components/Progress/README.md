# Progress

Halqa (`bd-ring`) va chiziq (`bd-bar`); foiz `--p` CSS oʻzgaruvchisi orqali (0–100).

- `bd-ring` 40px: kunlik missiya. `bd-ring--lg` 64px: natija. `bd-ring--hero`: yashil blok ichida (`sun` toʻldirish).
- `bd-bar` 6px: fan va yoʻnalish progressi. Rang ota elementdagi `is-<fan>` klassidan.
- Boʻsh iz `line` rangida — boʻsh progress ham koʻrinib tursin.
- Halqa ichida doim raqam (3/5, 84%) — rang yolgʻiz maʼno tashimaydi.
