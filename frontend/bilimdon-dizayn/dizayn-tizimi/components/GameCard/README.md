# GameCard

Oʻyin yoʻnalishi plitasi (`bd-dir`) va oʻyin kartasi (`bd-game`).

- Yoʻnalishlar 3 ustunli gridda: Xotira, Mantiq, Matematika, Diqqat, Fazoviy fikrlash, Soʻz va til.
- Oʻyin kartasi: 64px illyustratsiya plitasi, kategoriya (overline), nom, davomiylik/daraja, eng yaxshi ball chipi.
- “Tez orada” (`is-soon`): kichikroq (44px plita), soyasiz, 62% shaffof, “Tez orada” chipi — bosilmaydi.
