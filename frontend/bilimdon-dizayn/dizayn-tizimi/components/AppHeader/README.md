# AppHeader

Ixcham header (`header-h` 56px): avatar + salom bitta qatorda, oʻngda seriya va ball chiplari.

- Logo alohida qatorni egallamaydi; brendni maskot va rang koʻrsatadi. Kompyuterda logo yon panelda.
- Salom 17px/800, ostida sinf 12px `ink-3`. Ism uzun boʻlsa `text-overflow: ellipsis`.
- Chiplar: `fire` + kunlik seriya, `star` + jami ball. 0 boʻlsa ham koʻrinadi — motivatsiya.
- Ichki sahifalarda `bd-topbar` (52px): orqaga / yopish tugmasi, sarlavha, oʻngda bitta chip.
