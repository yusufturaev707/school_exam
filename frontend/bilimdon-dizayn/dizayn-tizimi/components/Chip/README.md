# Chip

Toʻliq yumaloq (`radius-full`) kichik yorliq: maʼlumot, holat yoki filtr.

- `bd-chip--stat` + `is-streak` / `is-star`: headerdagi 🔥 seriya va ⭐ ball. Ikonka yengil tebranadi (`bd-wiggle`).
- `bd-chip--status`: “Topshirish mumkin”, “Topshirildi” — `sun` fonda `on-sun` matn.
- `bd-chip--glass`: faqat `hero` ustida meta-maʼlumot (“45 ta savol”).
- `bd-chip--soft is-<fan>`: fan rangidagi meta.
- `bd-chip--filter`: tanlanadigan filtr, 36px + koʻrinmas hit-area = 44px. Tanlangani `brand-soft` + `brand` chegara.
- Balandlik `control-sm` (28px), yozuv 13px/800, ikonka 16px.
