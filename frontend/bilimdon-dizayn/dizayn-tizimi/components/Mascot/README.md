# Maskot

Yashil kitob maskoti — katta koʻzli, sariq xatchoʻpli; har bir ekranda bitta kayfiyatda, bitta joyda chiqadi.

**Kayfiyatlar** (`Bilimdon.mascot(mood, size)` yoki `<span data-mascot="salom" data-size="96">`):

| mood | qachon |
| --- | --- |
| `salom` | Kirish, profil, birinchi tashrif. Qoʻl silkitadi. |
| `ishora` | Asosiy amal yonida (hero) — tugmaga ishora qiladi. Doim tugmaning **oʻng** tomonida. |
| `oylayapti` | Kun savoli, boʻsh holatlar, oʻyin kirish ekrani. |
| `xursand` | Toʻgʻri javob seriyasi, natija ekrani, yangi nishon. |
| `hayron` | Xato javobdan keyin — har doim rag'bat so'zi bilan birga ("Hech gap emas, yana bir bor!"). |

**Oʻlchamlar:** hero ichida 88–96px, kartalarda 48–64px, boʻsh holat va natijada 120–140px.

**Qilinadi / qilinmaydi**
- Bir ekranda faqat bitta maskot. Konfetti va maskot birga faqat natija ekranida.
- Maskot ranglari (`#2e8b74` muqova, `#1f6f5f` tikuv, `#ffc94a` xatchoʻp) ikkala rejimda oʻzgarmaydi — u brend belgisi.
- Maskotni matn ostiga yoki kesilib qoladigan burchakka qoʻyma.
- Bu SVG skrinshotlardagi maskotning qayta chizilgan varianti; asl vektor fayllar boʻlsa, `assets/` ga yuklab, shu kayfiyatlar roʻyxati bilan almashtiring.
