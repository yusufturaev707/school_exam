# SubjectCard

Imtihon fani uchun ixcham karta (~104px): ikonka plitasi, nom, “15 ta savol”, ingichka progress.

- Uch ustunli gridda (`bd-subjects`, gap 8px) — telefon kengligida ham birinchi ekranga sigʻadi.
- Rang klassi: `is-math` (Σ, binafsha-koʻk), `is-logic` (jumboq, sariq-toʻq sariq), `is-lang` (kitob, pushti).
- Nom qisqa: “Matematika”, “Mantiq (IQ)”, “Ona tili” — toʻliq nom (“Ona tili va adabiyot”) `aria-label`da va tafsilot sahifasida.
- Natija boʻlsa meta “13/15 toʻgʻri” ga oʻzgaradi, progress `--p` foizi bilan toʻladi.
- Uzun tavsif kartada boʻlmaydi.
