# Card

Barcha kontent bloklari uchun asosiy konteyner: `card` fon, `radius-lg` (18px), `shadow-sm`.

- Ichki boʻshliq 12px (ixcham) yoki 16px (yon tomonlar); kartalar orasi `space-3`.
- `bd-card--cream`: iliq ikkinchi darajali karta (Kun savoli, maslahat).
- `bd-card--flat`: soyasiz, `line` chegarali — qulflangan yoki “Tez orada” elementlar.
- `bd-rowcard`: bir qatorli roʻyxat elementi, kamida 52px balandlik, chapda 32px ikonka plitasi.
- Bosiladigan karta `bd-tap` oladi (bosilganda `scale(.98)`).
- Rangli chap chegara (left-border accent) ishlatilmaydi.
