# QuestionCard

Kun savoli va oʻyin savollari: savol + 2×2 javob tugmalari (`bd-answers`).

- Javob tugmasi kamida 48px (`bd-answer`), oʻyinda 72px (`bd-answer--lg`), 3D pastki qirra bilan.
- Toʻgʻri: `success-soft` fon + `success` chegara + ✓ ikonka + “pop” animatsiya. Xato: `danger` + ✕ + “shake”. Rang yolgʻiz emas.
- Javobdan keyin maskot pufagi qisqa izoh beradi (13px/800).
- Bosh sahifada “Soʻnggi faoliyat” boʻsh boʻlganda shu karta chiqadi.
